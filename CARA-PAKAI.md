# 💕 Website Ulang Tahun untuk Merci

Website interaktif bertema pink untuk merayakan ulang tahun Merci, 23 Oktober 2026.

## Isi website
- Halaman pembuka dengan nama Merci dan tombol "Buka Kejutannya"
- Ucapan selamat ulang tahun
- 4 puisi romantis
- Galeri foto Merci
- Doa ulang tahun untuknya
- Pesan penutup dengan tombol ledakan hati 💖
- Backsound lagu "Setengah Lima - Sore"
- Hujan kelopak bunga & hati yang jatuh di latar belakang

## Langkah sebelum dibuka

### 1. Masukkan lagu
- Siapkan file lagu **Setengah Lima - Sore** dalam format `.mp3`
- Ganti namanya jadi **`setengah-lima.mp3`**
- Taruh di folder **`music/`**

### 2. Masukkan foto Merci
- Taruh foto di folder **`photos/`**
- Beri nama: `merci-1.jpg`, `merci-2.jpg`, ... sampai `merci-6.jpg`

### 3. Buka website
- Klik dua kali file **`index.html`** → akan terbuka di browser
- Klik tombol **"Buka Kejutannya 💝"** (klik pertama juga menyalakan musik,
  karena browser melarang musik berbunyi otomatis sebelum ada interaksi)
- Ada tombol musik ♪ di pojok kanan atas untuk menyalakan/mematikan lagu

## Catatan
- Semua teks (puisi, doa, pesan) bisa diubah. Tinggal buka `index.html`
  dan edit tulisannya. Bilang saja kalau mau aku ubahkan.
- Website ini sepenuhnya offline, tidak butuh internet (kecuali font online).

Selamat memberi kejutan! 🎀
